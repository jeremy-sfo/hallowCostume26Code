# hallowCostume26Code

experimental code for my future tv head cosplay for 2026 halloween

## Hardware

- ESP8266
- OLED display
- Potentiometer
- Buttons
- ...

## Current Features

- 5 head orientations
- Random idle animations
- Multi-direction blinking
- Potentiometer input
- Animation interruption when user moves the control

## Code Structure

### hallowCostume26.ino
Main Arduino setup and loop.

### Processing.ino
Input processing and animation scheduling.

### Oled.ino
OLED rendering and face selection.

### Animations.ino
Character animations and animation timing.

### Potentiometers.ino
Potentiometer reading and input detection.

### Bitmaps.ino
Generated bitmap data.

### Globals.h
Shared variables and declarations.

### Buttons.ino
Currently pretty useless (maybe future jeremy can put it to use?)
